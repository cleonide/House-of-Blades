# House of Blades Project Plan

## Project Goal

Create a simple two-page website for the fictional House of Blades barbershop.

## Work Breakdown Structure

1. Plan the website

2. Build the website

3. Create documentation

4. Test the project

## Risk Analysis

| Risk | Impact | Probability | Response |
|---|---|---|---|
| Website files have errors | Medium | Medium | Test each page before submitting |
| Website links do not work | Medium | Low | Check all links |
| Project files are missing | High | Low | Check the repository before submitting |
| Website takes longer than expected | Medium | Medium | Keep the website simple |

## TAME

### Transfer
GitHub Pages will be used to host the website instead of managing a separate web server.

### Avoid
Avoid adding unnecessary features that could make the project more complicated.

### Mitigate
Test the website and links before submitting the project.

### Accept
Small design or formatting issues may happen, but they can be fixed during the final review.
